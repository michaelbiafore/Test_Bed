# Purpose of this Directory
This directory is the result of a search for a curated set of "software engineering" skills and commands, proposed by many groups and instantiated in many repos. The goal of the curation is to find a minimally overlapping set of skills and commands that can help builders of agentic systems, notably the AI Fellows of Cohort 1, to produce code that is sufficiently conformant to widely accepted norms of software engineering practice that their code can be promoted to Dymon PROD with a minimum of additional reworking required by central IT. The documents titled **SE_for_AI_nn** contain details on the space of frameworks I searched through, the 4 non-overlapping frameworks I chose and the installation procedure, with Figures, for those frameworks. The **Test_Bed** directory is the clone of a GitHub repo in which the 4 frameworks (and nothing else) has been installed.
